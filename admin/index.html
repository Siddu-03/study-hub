How Publishing Works in a Static Architecture

  1. Local Draft: As you add or edit fields, domains, subjects, and topics, changes are saved to your browser's local draft.
  2. Export: Click "Download Complete Data Bundle (ZIP)" above.
  3. Incorporate into Project: Extract the contents of the ZIP file directly into your project's data/ directory, replacing the existing files.
  4. Git Commit & Deploy: Run git add data/ && git commit -m "Update curriculum data" && git push to publish your changes live to GitHub Pages or static hosting!
